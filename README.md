# AI Learns to Land

Chani Builds Project #003. The project name is a working title.

A learning project exploring rocket landing through Python,
physics simulation, control, and reinforcement learning.

## Roadmap

1. Set up the development environment and define requirements.
2. Build and validate a one-dimensional landing simulation.
3. Implement baseline controllers and visualize their behavior.
4. Train and evaluate a small reinforcement learning agent.
5. Document reproducible results and prepare a public release.
6. Extend the simulation to two dimensions.

## Current Status

Phase 0: development environment and requirements.

The local Python virtual environment and Git repository are set up.
The simulation has not been implemented yet.

## Development

- Python 3.14.7
- Visual Studio Code
- A project-local virtual environment in `.venv/`

Source code is written by the project author.
AI assists with design discussions, learning exercises, hints,
code review, and verification.
